GoldVault v2.3.1
📄 상세 내용
GoldVault에 $100 USD를 예치한 후 금코인(GLD)이 지급되지 않습니다. 재현 조건: • GoldVault에 $100 이상 USD 예치 • 대시보드에서 "처리 중" 상태 3시간 이상 지속 • 금코인 잔액 변동 없음 이상 현상: • 대시보드에 "처리 중"만 표시, 에러 없음 • 예치한 달러는 차감됨 • 이자 적립도 시작되지 않음 • Discord에서 5명 이상 동일 증상 제보
💡 해결 방향 제안
• deposit() 함수에서 goldCoin.mint() 호출 로직 확인 • 예치 큐(DepositQueue) 처리 worker 상태 점검 • USD→GLD 환율 오라클 응답 지연 여부 확인 • pending 트랜잭션 batch 처리 스케줄러 로그 확인 • 영향받은 유저 대상 수동 mint 조치 준비
💬 원문 제보
"$100 예치하고 3시간이 지났는데 금코인이 아직도 안 들어왔어요. 대시보드에는 '처리 중'이라고만 뜨고 이자도 안 붙고 있음. 다른 사람들도 같은 문제 있다고 디스코드에서 얘기하고 있어요."

@dave · backend
입력 프롬프트
GoldVault deposit() 함수에서 goldCoin.mint() 호출 전후 로직을 분석해줘. 특히 DepositQueue batch processor가 stuck 되는 시나리오를 찾아줘. 현재 pending 상태가 3시간 이상 지속되는 유저가 5명 이상이야.
AI 분석 결과
분석 완료: DepositQueue.processBatch()에서 USD→GLD 환율 오라클 호출 시 timeout 미설정 발견. 오라클 응답 지연 시 전체 batch가 블로킹되는 구조. 원인: GoldPriceOracle.getRate()의 기본 timeout이 무한대(0)로 설정됨 해결: timeout 30초 + fallback rate 적용 필요 영향: 현재 pending 유저 12명, 총 $4,800 미처리

@frank · smart-contract
입력 프롬프트
GoldCoin.sol의 mint() 함수 보안 검토해줘. 최근 v2.3.1 업데이트에서 변경된 부분 중 deposit 관련 side-effect 있는지 확인해줘.
AI 분석 결과
v2.3.1 변경사항 검토 완료: mint() 자체는 정상이나, 호출 조건인 _validateDeposit()에서 minimumDeposit 값이 $50 → $100으로 변경됨. 발견: $100 정확히 예치 시 >= 대신 > 비교로 off-by-one 에러 수정: GoldCoin.sol L142: require(amount > minDeposit) → require(amount >= minDeposit) 참고: $101 이상 예치한 유저는 정상 처리됨
